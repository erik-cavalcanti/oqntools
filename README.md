# oqntools
Versão 0.1.23. O objetivo desse repositório é publicar o código das funções utilizadas no plugin OQN Tools. Para baixar o plugin e utilizar é necessário entrar no site erikcavalcanti.com.br/oqn-tools. É necessário coletar os vossos emails para avisar de novas atualizações e funcionalidades.
# Projetos de terceiros

Algumas funcionalidades utilizam ou foram adaptadas de projetos de código aberto:

E-verse — Revit glTF Exporter: componentes relacionados à exportação de modelos 3D.

RvtVa3c — Jeremy Tammik: componentes e referências de implementação para exportação de geometria.

Os direitos autorais dos respectivos autores são preservados. As licenças originais estão disponíveis nesta pasta.

# Aviso

O OQN Tools é um projeto independente e não possui vínculo oficial com a Autodesk, E-verse ou os demais desenvolvedores mencionados.

A licença MIT do OQN Tools não substitui nem elimina as obrigações previstas nas licenças dos componentes de terceiros.
